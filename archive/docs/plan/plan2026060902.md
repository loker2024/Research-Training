# 下一步计划：步骤 5 消融实验

## Summary
当前 ETTh1 + ETTm1 的五步长正式核心实验已经完成，下一步进入消融实验。重点不再大规模重跑全部模型，而是围绕当前表现最强、最有论文特征的 Autoformer 和 PatchTST 验证关键模块贡献。

## Key Changes
- 新增消融模型入口，保持现有训练脚本接口不变，只扩展 `scripts/run_experiments.py` 的 `MODEL_BUILDERS`：
  - `autoformer_no_decomp`：关闭序列分解，直接用原序列进入编码器，趋势分支输出置零，用于验证 Series Decomposition。
  - `autoformer_no_autocorr`：将 Auto-Correlation 替换为标准多头自注意力，用于验证 Auto-Correlation。
  - `patchtst_no_patch`：不用 patch embedding，改为逐时间点线性投影，用于验证 Patching。
  - `patchtst_channel_mix`：不再按变量独立建模，直接混合多变量输入，用于验证 Channel Independence。
- 新增配置文件 `configs/ablation_etth1_ettm1.json`：
  - datasets：`ETTh1,ETTm1`
  - horizons：`96,336`
  - models：上述 4 个消融模型
  - 训练参数沿用正式实验：`epochs=20`、`patience=5`、`batch_size=32`、`lr=0.001`、`seed=42`、`sample_limit=0`
  - run tag：`ablation_seed42`
  - 启用 `skip_existing=true`
- 汇总消融结果：
  - 生成 `results/v1_csv/ablation/ablation_seed42_summary.csv` 与 `results/v1_md/ablation/ablation_seed42_summary.md`
  - 生成对比表，把消融结果与 `formal_seed42` 中对应原模型并排展示，字段包含 MSE、MAE、R²、参数量、训练耗时。
- 更新文档：
  - `docs/progress.md` 记录消融设计、运行范围、生成文件、测试结果和下一步。
  - `README.md` 增加消融实验运行命令。
  - 可将过时的 `docs/plan/plan2026060901.md` 更新为当前计划，避免继续指向已完成任务。

## Test Plan
- 代码级验证：
  - `python -m py_compile models/*.py scripts/run_experiments.py scripts/summarize_results.py`
  - 对 4 个消融模型做前向 shape smoke test：输入 `(2, 96, 7)`，horizon `96/336`，输出必须为 `(2, horizon, 7)`。
- 训练级验证：
  - 先用 `sample_limit=128`、`epochs=1` 跑 `ETTh1 h96` 四个消融模型，run tag 用 `ablation_smoke`。
  - smoke 通过后运行正式消融配置。
- 结果验收：
  - 每个组合生成 `_results.npy` 和 `_summary.json`。
  - 消融正式矩阵覆盖 `2 数据集 × 2 步长 × 4 消融模型 = 16` 个实验。
  - 对比表能明确回答：Autoformer 的分解/自相关是否有效，PatchTST 的 patching/channel independence 是否有效。

## Assumptions
- 当前不重跑 `formal_seed42` 核心实验，只复用已有 50 个正式结果作为对照。
- ECL 暂不进入消融主矩阵；等消融完成后再做 `ECL h96` 高维 smoke 或附录实验。
- 项目下一阶段目标是形成报告可用证据，而不是继续做大规模调参。
