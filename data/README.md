## 实验使用的数据集

当前精简实验使用 **ETTh1、ETTm1、ECL** 三个数据集，覆盖不同采样频率和变量规模。

### 1. ETTh1 — 电力变压器温度（小时级）

| 属性     | 值                          |
| ------ | -------------------------- |
| 来源     | Electricity Transformer Temperature |
| 采样频率   | 1 小时                        |
| 时间列    | `date`                      |
| 特征列数   | 7                           |
| 样本行数   | 17,420                      |
| 切分方式   | 前 12 月训练 / 4 月验证 / 4 月测试    |
| 目标列    | `OT`（Oil Temperature，油温）    |

**特征说明：**

| 列名     | 含义                    |
| ------ | --------------------- |
| `HUFL` | High UseFul Load（高有用负载） |
| `HULL` | High UseLess Load（高无用负载） |
| `MUFL` | Middle UseFul Load（中有用负载） |
| `MULL` | Middle UseLess Load（中无用负载） |
| `LUFL` | Low UseFul Load（低有用负载）   |
| `LULL` | Low UseLess Load（低无用负载）  |
| `OT`   | Oil Temperature（油温，预测目标） |

> ETT 数据集来自某电力变压器的 SCADA 传感器读数。HUFL/HULL/MUFL/MULL/LUFL/LULL 分别对应高/中/低层绕组的有功与无功负载，OT 为变压器油温。


### 2. ETTm1 — 电力变压器温度（15 分钟级）

| 属性     | 值                          |
| ------ | -------------------------- |
| 来源     | Electricity Transformer Temperature |
| 采样频率   | 15 分钟                      |
| 时间列    | `date`                      |
| 特征列数   | 7                           |
| 样本行数   | 69,680                      |
| 切分方式   | 前 12 月训练 / 4 月验证 / 4 月测试    |
| 目标列    | `OT`（Oil Temperature，油温）    |

**特征说明：** 与 ETTh1 相同的 7 列（HUFL, HULL, MUFL, MULL, LUFL, LULL, OT），区别在于采样频率为 15 分钟，因此样本量是 ETTh1 的 4 倍。


### 3. ECL — Electricity Consuming Load（电力负荷）

| 属性     | 值                       |
| ------ | ----------------------- |
| 来源     | UCI Electricity Load Diagrams |
| 采样频率   | 1 小时                     |
| 时间列    | `date`                   |
| 特征列数   | 321                      |
| 样本行数   | 26,304                   |
| 切分方式   | 70% 训练 / 10% 验证 / 20% 测试 |
| 目标列    | `OT`（总负荷，Total Load）     |

**特征说明：**

- 列 `0` ~ `319`：321 个不同客户端/区域的电力消耗值，列名为匿名编号
- 列 `OT`：聚合总负荷（预测目标）

> ECL 数据集包含 321 个客户端的小时级用电数据，变量数远多于 ETT 系列，是多变量长时序预测的典型基准数据集。

## 三种数据集在本次实验中的作用

本次实验选取 ETTh1、ETTm1、ECL 三个数据集，旨在从**采样频率**和**变量维度**两个正交维度全面评估模型的长时序预测能力：

| 数据集   | 频率    | 变量数 | 实验作用                                                   |
| ----- | ----- | --- | ------------------------------------------------------ |
| ETTh1 | 1h    | 7   | **低频少变量基线**：数据量小、训练快，便于快速迭代和验证模型基础性能，也是时序预测论文的标准基准。      |
| ETTm1 | 15min | 7   | **高频同源对照**：与 ETTh1 来自同一变压器但采样更密，特征相同而样本量 4 倍，用于检验模型对高频率细粒度时序的利用能力及频率差异下的泛化性。 |
| ECL   | 1h    | 321 | **高维多变量挑战**：变量数远超 ETT 系列，跨客户端间存在复杂耦合关系，用于测试模型在高维场景下的可扩展性与计算效率，并对比通道混合（Transformer/Informer/Autoformer）与通道独立（PatchTST）策略的差异。 |

三者搭配使得实验能同时回答：模型在不同时间粒度、不同变量规模下是否稳健，以及哪些架构在何种数据特性上具备优势。

## 训练集、验证集、测试集在本次实验中的作用

三个数据集均按时间顺序划分为训练集、验证集、测试集，严格禁止打乱顺序（避免未来信息泄露）。各划分的具体作用如下：

### 训练集（Train Set）

- **用途**：模型参数学习的唯一数据来源。损失函数在训练集上计算梯度并反向传播，驱动权重更新。
- **标准化**：仅使用训练集的均值和方差对三个子集做 Z-score 标准化（`scaler.npz` 中保存的 `mean` 和 `scale`），确保验证集和测试集不参与统计量估计，防止数据泄露。
- **窗口生成**：通过滑动窗口（回看 96 步 → 预测 H 步）将训练序列切割为重叠样本，X 形状为 `(samples, 96, features)`，Y 形状为 `(samples, H, features)`。

### 验证集（Validation Set）

- **用途**：超参数调优与早停判定的依据。训练过程中持续监控验证集损失，当连续多轮不再下降时触发早停（Early Stopping），防止过拟合。
- **不参与梯度更新**：验证集仅做前向推理计算指标，不回传梯度，模型权重不会因验证集而改变。
- **模型选择**：保存验证集损失最低的检查点作为最终模型，而非训练损失最低或最后一个 epoch 的模型。

### 测试集（Test Set）

- **用途**：最终性能评估的唯一标准。所有实验指标（MSE、MAE 等）仅在测试集上报告，确保结果可与其他论文公平对比。
- **严格隔离**：测试集在训练和调参阶段完全不可见——既不参与梯度更新，也不参与超参数选择或早停判定。只有当模型和超参数全部确定后，才在测试集上做一次最终评估。
- **报告结果**：本项目中 `results/` 目录下的对比表格全部基于测试集指标生成。

### 各数据集的划分比例

| 数据集   | 训练集            | 验证集           | 测试集           |
| ----- | -------------- | ------------- | ------------- |
| ETTh1 | 前 12 月（8,640 行） | 接下来 4 月（2,880 行） | 最后 4 月（5,900 行） |
| ETTm1 | 前 12 月（34,560 行）| 接下来 4 月（11,520 行）| 最后 4 月（23,600 行）|
| ECL   | 前 70%（18,412 行） | 接下来 10%（2,631 行）| 最后 20%（5,261 行）|

> ETT 系列按固定月数切分，ECL 按比例切分。切分后每个子集再经滑动窗口展开为 `(X, Y)` 样本对，因此实际可用样本数会少于原始行数。
