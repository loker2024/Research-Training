# 时间序列预测研究项目 — 实施步骤

## 项目总览

基于 LSTM、Transformer 及其高效变体（Informer/Autoformer/PatchTST）开展时间序列预测研究，探索多尺度时序分解、外生变量融合与概率预测技术，解决长序列依赖建模与计算效率问题。

---

## 第 1 步：环境搭建与数据准备

- 安装 PyTorch 及相关依赖库
- 下载并处理 ETTh1、ETTm1 两个公开 ETT 数据集
- 数据预处理：归一化、滑动窗口划分样本
- 按时间顺序切分训练/验证/测试集，确保无数据泄露

## 第 2 步：基础模型实现

- 实现 LSTM 基线模型
- 实现 Transformer 基线模型
- 统一训练框架（数据加载、训练循环、评估逻辑）

## 第 3 步：高效变体模型实现

- 实现 Informer
- 实现 Autoformer
- 实现 PatchTST
- 确保各模型共享同一套数据接口和评估流程

## 第 4 步：核心实验运行

- 在 ETTh1、ETTm1 上运行所有模型
- 设置多变量和单变量两组实验
- 预测步长：24 / 48 / 96 / 168 / 336
- 记录 MSE、MAE、MAPE 指标

## 第 5 步：消融实验

- 设计消融方案（去掉时序分解模块、去掉外生变量融合等）
- 对比有无关键组件的性能差异
- 验证各模块的有效性

## 第 6 步：可视化与深入分析

- 绘制预测值 vs 真实值对比曲线
- 绘制残差分析图
- 分析误差累积现象
- 分析长期预测性能衰减问题
- 计算复杂度对比（参数量、训练/推理时间）

## 第 7 步：撰写实验报告

- 整理所有实验结果和图表
- 超参数调优经验总结
- 季节波动性讨论
- 模型架构对比分析
- 结论与展望

---

## 推荐执行顺序

```
数据准备 → 基础模型 → 高效变体 → 跑实验 → 消融实验 → 可视化分析 → 写报告
```

每一步都是下一步的基础，按此顺序推进最稳妥。
