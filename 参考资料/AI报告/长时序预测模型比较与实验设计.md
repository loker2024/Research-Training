# 长时序预测模型比较与实验设计

## 摘要

这篇资料比较了 LSTM、标准 Transformer、Informer、Autoformer 与 PatchTST 在长时序预测中的定位、公开 benchmark 表现、复杂度差异，以及面向统一复现实验的设计方案。核心判断是：如果目标是公开多变量 point forecast 的精度，PatchTST 更接近当前强基线；如果目标是解释长期预测为什么稳定或衰减，Autoformer 的渐进式分解与 Auto-Correlation 提供了更清楚的机制证据；Informer 的历史价值在于把稀疏注意力和 direct multi-step 解码推到长时序场景，但后续点预测精度已被更强结构超过；LSTM 更适合作为低资源或递归预测的参考底线。

## 关键要点

- 公开论文主表与目标实验步长并不完全重合：ETT、ECL、Traffic 常用 96/192/336/720，ILI 常用 24/36/48/60；若要比较 24/48/96/168/336，需要单独做统一复现。
- PatchTST 的优势主要来自 patch tokenization 与 channel-independence：它把时间点级 token 改成子序列 patch token，降低注意力开销，并允许更长 look-back。
- Autoformer 的价值不只是精度，而是证明“嵌入式、可联训的渐进式分解”比外部先验分解更适合长 horizon。
- Informer 解决了标准 Transformer 在长序列中的二次复杂度和自回归误差累积问题，但在后续公开 benchmark 中点预测精度通常不如 PatchTST 与 Autoformer。
- 外生变量融合与概率预测在经典公开主表里没有完整 apples-to-apples 结果，更适合作为统一复现实验中的扩展模块。

## 详细说明

### 1. 研究边界

资料强调不要把跨论文、不同 split、不同 look-back 的数字机械拼成一个总排行榜。更稳妥的做法是双轨评估：

1. **文献复核线**：沿用原论文公开 horizon、split 和主表结果，用于判断社区共识下的模型强弱。
2. **统一复现线**：固定 24/48/96/168/336、chronological split、统一滑窗、统一评价指标和统一外生变量接口，用于回答自定义课题下模型是否仍然成立。

这一区分很重要，因为公开资料中不存在一张同时覆盖 LSTM、标准 Transformer、Informer、Autoformer、PatchTST，并在 ECL、ETTh1/ETTh2/ETTm1/ETTm2、ILI、Traffic 上统一跑完 24/48/96/168/336 的完整主表。

### 2. 数据集与预处理

主要数据集包括 ETT、ECL/Electricity、Traffic 与 ILI。资料中给出的处理原则是：

- 按时间顺序切分数据，避免随机打乱造成未来信息泄露。
- 缩放统计量只在训练集估计，再应用到验证集和测试集。
- 多变量任务采用 M→M：输入全部通道，输出全部通道。
- 单变量任务采用 S→S：只保留目标通道并预测目标通道。
- ETT、ECL、Traffic 可把 look-back 映射为：24→96、48→192、96→336、168→720、336→720。
- ILI 的公开主设定本来较短，扩展到 96/168/336 时应单独报告，不与公开主表直接横向比较。

### 3. 模型定位

| 模型 | 主要机制 | 在资料中的定位 |
| --- | --- | --- |
| LSTM | 门控递归状态 | 低资源、递归预测或概率建模参考线；长 horizon 精度通常落后。 |
| 标准 Transformer | 全局 self-attention | 统一复现实验中必要的基线，但长序列计算和显存压力较大。 |
| Informer | ProbSparse attention、自注意力 distilling、一次性生成式 decoder | 长时序高效 Transformer 的早期关键路线，减少自回归误差累积，但公开点预测精度已不占优。 |
| Autoformer | 渐进式分解、Auto-Correlation | 提供强机制证据，尤其适合解释趋势、周期与长期稳定性。 |
| PatchTST | patch token、channel-independence | 公开多变量 point forecast 中综合表现最强，适合长 look-back 与高维序列。 |

### 4. 公开结果中的稳定判断

资料摘取的公开可比结果显示，PatchTST/42 在多个主任务上显著优于 Autoformer 与 Informer。例如：

- ECL 96 步：PatchTST/42 为 0.130/0.222，Autoformer 为 0.196/0.313，Informer 为 0.304/0.393。
- Traffic 96 步：PatchTST/42 为 0.367/0.251，Autoformer 为 0.597/0.371，Informer 为 0.733/0.410。
- ILI 24 步：PatchTST/42 为 1.522/0.814，Autoformer 为 2.906/1.182，Informer 为 4.657/1.449。

这些数字支持一个分层判断：PatchTST 往往拥有更低误差底座；Autoformer 仍是强基线，尤其在趋势和周期明显的数据上有机制优势；Informer 更像重要历史基线而非当前最强精度模型。

### 5. 多尺度分解与长期稳定性

Autoformer 的消融结果是资料中最有解释力的一部分。它说明分解不是简单预处理，而应该尽量嵌入网络内部并端到端学习。公开消融中，加入 progressive decomposition 后，普通 Transformer 在 720 步上的 MSE 从 2.672 降到 0.537，Informer 从 3.379 降到 0.822；而简单“先分解再分别预测”的外部分解并不稳定，超长 horizon 下甚至可能变差。

因此，在统一实验里，多尺度分解至少应设置四档：无分解、外部 STL、外部 EMD/SSA、内部 learnable decomposition。这样才能区分“分解思想有效”与“某种固定预处理有效”。

### 6. 外生变量融合与概率预测

经典长时序 benchmark 通常没有系统比较 heterogeneous covariates，因此资料建议把外生变量融合设计成扩展模块，而不是直接从公开主表得出结论。可比较三种路线：

- 直接拼接 concat：适合时间戳、节假日、工作日等简单未来可知特征。
- 双编码器 cross-attention：适合外生变量结构与主序列差异较大时。
- conditional encoding 或 gating：适合借鉴 TFT 的特征选择思想，抑制无关变量。

概率预测建议优先比较两条路线：MC Dropout 与分位数回归。MC Dropout 改动小但推理成本随采样次数增加；分位数回归更适合直接输出区间，并可用 pinball loss 训练。

### 7. 复杂度与工程资源

资料提醒不要只看理论复杂度。LTSF-Linear 中 Electricity 的统一实测显示，标准 Transformer、Informer、Autoformer 的参数量、MACs、推理时间和显存占用并不严格按理论复杂度排序；Informer 理论上更省，但 wall-clock 不一定更快；Autoformer 机制更强，但实现开销和显存峰值可能更高。PatchTST 的 patching 则通过减少 token 数，在部分 case 中带来明显运行时间收益。

统一复现实验应固定 profiler 输出：参数量、MACs、推理时间、显存峰值。否则很容易把“理论更高效”误读成“实际更快”。

### 8. 推荐实验路线

资料建议的执行顺序是：

1. 固定 split、horizon 和 no leakage 规则。
2. 先比较 backbone 与 seq_len，因为它们决定性能上限。
3. 再调 decomposition kernel 与 patch_len/stride。
4. 有真实未来可知 covariates 时再引入外生变量融合。
5. 最后加入概率预测头，比较 MC Dropout 与 quantile head。
6. 对每个模型保存预测曲线、残差图、误差随 horizon 变化曲线、箱线图与复杂度-精度 Pareto 图。

一个实用的最终组合是：PatchTST 主干 + 可学习多尺度分解 + 条件式外生变量编码 + 分位数预测头，并用 MC Dropout 作为不确定性校准的交叉检查工具。
