# Autoformer: Decomposition Transformers with Auto-Correlation for Long-Term Series Forecasting

## 一、30 秒速览

* **一句话概括**：Autoformer 将序列分解（趋势+季节）内嵌到 Transformer 架构中，并用自相关机制替代自注意力，从频域高效捕获周期性依赖，在长序列预测上大幅超越前代方法。
* **研究问题**：长序列时序预测中，趋势和季节成分纠缠在一起，现有方法无法有效分离并利用周期性模式；同时自注意力在长序列上的计算成本高且缺乏对周期性的显式建模。
* **核心方法**：(1) 深度分解架构（Series Decomposition Block 内嵌于 Encoder-Decoder 各层，逐层提取趋势和季节）；(2) 自相关机制（Auto-Correlation）替代自注意力，基于频域聚合 Top-k 周期分量。
* **主要结果**：在 6 个基准数据集上平均 MSE 降低 38%（相对提升），显著优于 Informer、LogTrans 等方法；在预测步长 720 时优势最明显。
* **最大创新**：将经典时间序列分解思想（趋势-季节分解）嵌入到深度学习架构的每一层，而非仅在预处理或后处理中做分解；自相关机制从频域显式捕获周期性依赖。
* **最大局限**：自相关机制依赖 FFT，对非周期性或弱周期性序列的优势可能减弱；分解块中的移动平均对突变（如突发事件）响应迟缓。
* **阅读建议**：⭐⭐⭐⭐⭐ 强烈推荐。这是将经典信号处理思想与现代深度学习深度融合的典范工作，思维方式的转变（从注意力到自相关）值得深入体会。

## 三、研究背景

### 3.1 论文研究什么

长序列时序预测（LSTF）——与 Informer 相同的问题设定，但 Autoformer 特别关注序列内部的**趋势-季节性纠缠**问题，以及**周期性依赖**的高效建模。

### 3.2 为什么这个问题重要

- 真实时序数据往往包含明显的趋势（长期走向）和季节性（周期波动），两者纠缠使得模型难以分别捕获。
- 现有 Transformer 方法（如 Informer）试图让注意力机制"自己学到"模式，但没有显式的周期性建模，导致在长预测步长下表现不佳。
- 经典的分解方法（如 STL、移动平均）只在预处理中使用，未与深度模型深度融合。

### 3.3 现有方法有什么不足

| 方法类型 | 问题 |
|---------|------|
| **经典分解（STL 等）** | 只做预处理/后处理，分解与模型训练脱节；无法端到端学习 |
| **Informer** | ProbSparse 注意力虽降低了复杂度，但仍是"逐点"比较，缺乏对周期性模式的显式利用；长预测步长下性能衰减 |
| **Reformer / LogTrans** | 局部稀疏注意力，难以捕获长程周期性 |
| **标准 Transformer** | O(L²) 复杂度 + 逐点注意力不擅长建模周期 |

**核心观察**：传统注意力是"点对点"的（某个时间步关注另一个时间步），而时序预测真正需要的是"周期对周期"的——比如今天的用电模式与昨天同时刻、上周同日的模式高度相关。

## 四、核心方法

### 4.1 整体思路

Autoformer 的核心创新是将**序列分解**从"外围操作"升级为"架构内建操作"：

1. **Series Decomposition Block**：将序列分解为趋势（Trend）和季节（Seasonal）两部分，嵌入到模型的每一层。
2. **Auto-Correlation Mechanism**：替代自注意力，在频域通过 FFT 计算自相关，选取 Top-k 周期分量进行加权聚合。
3. **Decomposed Encoder-Decoder**：编码器逐层提取季节成分，解码器分别处理趋势和季节，最终合并输出。

### 4.2 模型输入与输出

- **输入**：历史序列 X ∈ ℝ^{L×d}（L 个时间步，d 个变量）
- **输出**：预测序列 Ŷ ∈ ℝ^{H×d}（H 个时间步的预测）
- **分解**：输入先经过分解块：X = Trend(X) + Seasonal(X)，两部分分别在模型中独立处理。

### 4.3 模型结构

```
输入序列 X ∈ ℝ^{L×d}
    │
    ├─→ 分解 ─→ Trend₀  ─────────────────────────────────────────────→ 累加趋势
    │       └─→ Seasonal₀ ─→ Encoder（处理季节分量）
    │                              │
    │                              ▼
    │                        ┌──────────────────────────────┐
    │                        │  Encoder Block                 │
    │                        │  Auto-Correlation → 分解       │
    │                        │  Feed-Forward → 分解           │
    │                        │  每层输出：季节→下一层，       │
    │                        │            趋势→累加            │
    │                        └──────────────────────────────┘
    │                              │ 编码器输出的季节分量
    │                              ▼
    │                        ┌──────────────────────────────┐
    │                        │  Decoder Block ×N              │
    │                        │                                 │
    │                        │  内部自相关（Masked）→ 分解     │
    │                        │  交叉自相关（与编码器）→ 分解   │
    │                        │  Feed-Forward → 分解            │
    │                        │                                 │
    │                        │  每层输出：季节→下一层，        │
    │                        │            趋势→累加            │
    │                        └──────────────────────────────┘
    │                              │
    │                              ▼
    │            解码器季节分量 + 编码器季节分量的交叉关联
    │                              │
    ▼                              ▼
  累加趋势 ──────────────────→ + ←─ 季节性预测 ←── 映射 ── Seasonal part
                              │
                              ▼
                     最终预测 Ŷ ∈ ℝ^{H×d}
```

### 4.4 核心创新模块

#### 4.4.1 Series Decomposition Block

**直觉**：经典时序分析中，序列 = 趋势 + 季节。趋势是平滑的低频成分，季节是周期性的高频成分。通过移动平均提取趋势，原序列减去趋势得到季节。

$$\text{Decompose}(X) = \text{Trend}(X), \text{Seasonal}(X)$$
$$\text{Trend}(X) = \text{AvgPool}(X) \quad \text{（移动平均）}$$
$$\text{Seasonal}(X) = X - \text{Trend}(X)$$

**关键设计**：分解不是只做一次，而是嵌入到模型的每一层。这样后续层可以逐步细化趋势和季节的分离，类似残差学习的思想。

#### 4.4.2 Auto-Correlation Mechanism

**直觉**：自相关性衡量序列在不同时间延迟下的相似度。如果序列有周期 T，那么延迟 T 的自相关值会很高。Autoformer 利用这个性质，在频域高效计算自相关，找到最显著的周期，然后基于这些周期进行信息聚合。

**计算步骤**：
1. 对查询 Q 和键 K 分别做 FFT，转换到频域。
2. 在频域计算自相关：R(τ) = FFT(Q) · conj(FFT(K)) / L（即频域的互相关）。
3. 对 R(τ) 做 IFFT 得到时域自相关。
4. 选取自相关值最大的 Top-k 个延迟 τ₁, τ₂, ..., τₖ。
5. 对应延迟位置的值 V 进行加权求和，权重由自相关值决定。

**与自注意力的本质区别**：
- 自注意力：每个查询关注"与谁最相似"（内容相似性）
- 自相关：每个查询关注"哪些周期最显著"（周期依赖性）

#### 4.4.3 Decomposed Encoder-Decoder

**关键设计**：
- 编码器：只处理季节分量，逐层细化分解（每层都做一次 Decompose），趋势分量逐层累加但不经过注意力。
- 解码器：分别处理趋势和季节。交叉自相关将编码器的季节信息传递给解码器。
- 最终输出 = 趋势累加 + 季节预测。

### 4.5 完整数据流程

1. 输入序列 X 先经过分解：X → Trend₀ + Seasonal₀。
2. Seasonal₀ 进入编码器，经过 N 层 Auto-Correlation + Decompose，逐层提取更"纯"的季节成分，趋势残差逐层累加。
3. 解码器输入：[已知序列的季节分量 | 零占位的季节分量] + [趋势初始值]。
4. 解码器每层：内部 Masked Auto-Correlation + 交叉 Auto-Correlation（与编码器交互）+ Decompose，同样分别处理趋势和季节。
5. 最终预测 = 所有趋势累加 + 最终季节分量的线性投影。

## 五、关键公式

### 公式 1：序列分解

$$\mathcal{X} = \mathcal{X}_\text{trend} + \mathcal{X}_\text{seasonal}$$
$$\mathcal{X}_\text{trend} = \text{AvgPool}_k(\mathcal{X})$$
$$\mathcal{X}_\text{seasonal} = \mathcal{X} - \mathcal{X}_\text{trend}$$

* **公式作用**：将时序分解为趋势（低频平滑部分）和季节（周期波动部分）。
* **直觉理解**：移动平均就像低通滤波器，提取缓慢变化的趋势；原序列减去趋势，剩下快速波动的季节成分。
* **符号含义**：
  - X：原始序列
  - X_trend：趋势成分（移动平均后的平滑值）
  - X_seasonal：季节成分（原序列 - 趋势）
  - AvgPool_k：核大小为 k 的移动平均（论文中 k=25）
* **设计原因**：分解不是只做一次——嵌入到每层中，让网络逐步细化分解，类似 ResNet 的残差学习思路（每层看的是残差，逐层频繁分解比一次性分解更有效）。

### 公式 2：自相关计算（频域）

$$R_{Q,K}(\tau) = \frac{1}{L} \sum_{l=1}^{L} Q_l \cdot K_{l+\tau}$$

在频域通过 FFT 加速：

$$R_{Q,K} = \text{IFFT}\left(\overline{\text{FFT}(Q)} \odot \text{FFT}(K)\right)$$

* **公式作用**：计算序列在不同延迟 τ 下的自相关值，衡量周期性依赖。
* **直觉理解**：这是信号处理中的互相关（cross-correlation）。如果序列存在周期 T，那么延迟 T 的自相关值就会出现尖峰。频域计算等价于两个信号的频谱相乘再变换回来，时间复杂度 O(L log L)。
* **符号含义**：
  - Q, K：查询和键的序列
  - τ：时间延迟
  - FFT / IFFT：快速傅里叶变换及其逆变换
  - ⊙：逐元素乘法
  - 上划线：共轭（conjugate）
* **设计原因**：时域直接计算自相关的复杂度是 O(L²)，但频域利用 FFT 可将复杂度降至 O(L log L)。这是自相关机制高效的关键。

### 公式 3：Top-k 延迟选择与加权聚合

$$\text{AutoCorrelation}(Q, K, V) = \sum_{i=1}^{k} \text{softmax}(R_{Q,K})_i \cdot \text{Roll}(V, \tau_i)$$

* **公式作用**：选取自相关值最大的 k 个延迟 τ₁...τₖ，将对应位置的值加权聚合。
* **直觉理解**：不是像注意力那样"每对位置计算一个分数"，而是"找到最显著的 k 个周期，按这些周期的延迟去聚合信息"。比如如果发现延迟 τ=24（小时）的自相关最高，就把 24 小时前的值拿来作为重要参考。
* **符号含义**：
  - k：选取的 Top-k 延迟数
  - τᵢ：第 i 个最显著延迟
  - Roll(V, τ)：将 V 沿时间轴移动 τ 个位置
  - softmax(R)：将自相关值归一化为权重
* **设计原因**：融合了"周期发现"和"信息聚合"——先找到信号中最显著的周期，然后按这些周期提取和聚合信息。相比自注意力的逐对计算，更符合时序数据的周期性本质。

## 七、实验结果

### 7.1 主结果

| 数据集 | 预测步长 | Autoformer vs Informer MSE 提升 |
|--------|---------|--------------------------------|
| ETTh1 | 720 | 约 -25% ~ -30% |
| ETTm1 | 720 | 约 -20% ~ -25% |
| Weather | 720 | 约 -15% ~ -20% |
| ECL | 336 | 约 -10% ~ -15% |
| Traffic | 336 | 约 -5% ~ -10% |
| Exchange | 720 | 约 -30% ~ -40% |

> 注：以上为论文数据近似值，原文以具体数值为准。Autoformer 声称在 6 个数据集上平均 MSE 降低 38%。

**关键发现**：
- Autoformer 在几乎所有设置上优于 Informer。
- 预测步长越长，优势越明显（与分解和自相关捕获长程周期的能力一致）。
- 在 Exchange（金融数据，周期性较弱）上也有显著提升，说明方法不严格依赖周期性。
- 在 Traffic（高维，862 变量）上优势相对较小。

### 7.2 消融实验

| 变体 | 说明 | 效果 |
|------|------|------|
| 完整 Autoformer | — | ✅ 最优 |
| 用标准自注意力替代自相关 | AutoCorrelation → Self-Attention | 性能下降 + 计算成本增加 |
| 去掉分解块 | Decompose → Identity | 性能下降（趋势和季节纠缠导致预测不准） |
| 去掉分解块，只做预处理分解 | 仅输入分解 | 有提升但不如内嵌分解 |
| 仅用趋势或仅用季节 | 去掉其中一个分支 | 性能下降，说明两者都需要 |

**关键结论**：
- 分解块内嵌到每层的效果远优于只在输入端做一次分解。
- 自相关机制优于标准自注意力，尤其在长序列上。
- 趋势和季节两个分支缺一不可。

### 7.3 可视化结果

论文提供了分解可视化：
- 编码器各层的趋势 / 季节分解逐步细化。
- 解码器输出的趋势预测（平滑延展）和季节预测（周期波动）清晰分离。
- 自相关注意力图呈现明显的周期性条纹（与延迟 τ₁, τ₂ 对齐），对比标准自注意力的块状模式。

### 7.4 结果是否支持作者结论

**支持的部分**：
- 内嵌分解确实优于输入端一次性分解，证明"逐层分解"的有效性。
- 自相关机制在长预测步长上优于自注意力，符合"周期驱动聚合"的直觉。
- 在多个数据集上的优势一致性较强。

**需要警惕的部分**：
- "38% 相对提升"的统计方式（对所有数据集和步长取平均）可能放大了个别设置的极端值。
- 在 ETTm2 短步长（如 24 步）上与 Informer 差距很小，说明自相关在短预测时优势不大。

## 八、审稿人视角

* **创新性**：⭐⭐⭐⭐⭐ 很高。将信号处理中的分解与自相关思想"原生地"融入 Transformer 架构，而非简单的外围处理。这是方法论层面的创新，而非工程调参。
* **实验充分性**：⭐⭐⭐⭐ 充分。6 个数据集 + 多种步长 + 消融实验 + 可视化分析，覆盖面广。
* **对比公平性**：⭐⭐⭐ 中等。基线包含 Informer 等主要竞争方法，但未与充分调参的 vanilla Transformer 对比；部分基线的超参数可能未充分调优。
* **统计可靠性**：⭐⭐⭐ 中等。报告了多次运行均值，但部分设置缺乏标准差或置信区间。
* **潜在问题**：
  - 移动平均核大小 k=25 是硬编码，对不同频率的数据可能需要调整但论文未讨论。
  - FFT 假设信号近似平稳，对非平稳数据（如金融、突发事件）的理论保证较弱。
  - Top-k 延迟选择的 softmax 温度参数未详细讨论。
* **论文局限**：
  - 分解的假设（趋势 = 移动平均）在某些数据上可能过于简化（如阶梯状趋势）。
  - 高维数据（如 Traffic, 862 变量）上提升有限，通道间的交叉关系未显式建模。
  - 未讨论与频域方法（如 FEDformer）的比较，因为 FEDformer 是后续工作。
* **总体评价**：⭐⭐⭐⭐⭐ 优秀工作。分解思想的内嵌是自然且优雅的设计，自相关机制有理论支撑且实验结果扎实。该论文直接催生了后续一系列"分解+"方法的研究。

| moving_avg | 25 | 移动平均核大小（分解块） |
| factor | 1 | Top-k 因子（自相关中选取的延迟数） |
| distil | True | 是否使用蒸馏（编码器中） |

### 9.7 论文未说明的信息

### 9.8 可能踩坑点

1. **移动平均核大小（moving_avg）**：默认 k=25，适合小时级数据。对于 15 分钟级数据（ETTm1），可能需要调整。建议从 k=25 开始尝试 k∈{12, 25, 36, 48}。
2. **factor 参数**：自相关中选取的延迟数 factor × log(L)，论文默认 1。增大 factor 会选取更多延迟，可能对多周期数据有益。
3. **FFT 精度**：PyTorch 的 FFT 实现在不同平台可能有微小差异，影响浮点结果的可重复性。
4. **标签长度（label_len）**：与 Informer 相同，需与 seq_len 配合设置。
5. **内存消耗**：自相关机制虽然理论复杂度 O(L log L)，但实际显存占用仍然较大，高维数据 + 长序列可能需要减小 batch_size。
6. **数据格式**：Autoformer 仓库的数据格式与 Informer 仓库略有不同，需要注意列名和时间戳格式。

### 9.9 最小复现方案

1. 克隆仓库 `https://github.com/thuml/Autoformer`
2. 下载 ETTh1 数据集，放入 `datasets/` 目录
3. 安装 PyTorch 和基础依赖
4. 运行：
   ```bash
   python run.py --model Autoformer --data ETTh1 --pred_len 336 --seq_len 96
   ```
5. 观察输出的 MSE/MAE，与论文 Table 1 对比

### 9.10 复现成功标准

- 在 ETTh1 上 pred_len=336 时 MSE 达到论文报告值的 ±10% 范围内
- 在 Weather 上 pred_len=720 时 MSE 达到论文报告值的 ±10% 范围内
- 分解可视化结果与论文一致（趋势平滑、季节周期波动）

## 十、最终总结

* **这篇论文真正的新意是什么**：
  1. **内嵌分解**：将经典时序分解从"外围预处理"移到"架构核心"，让分解和表示学习联合优化，这是方法论层面的突破。
  2. **自相关机制**：从频域利用 FFT 显式发现和利用周期性，替代了自注意力的"逐对比较"模式，是真正面向时序的注意力替代。

* **最值得学习的部分**：
  1. 如何将经典信号处理思想（分解+自相关）与现代深度学习架构有机融合——不是简单堆叠，而是让每个组件都围绕分解设计。
  2. 自相关的频域推导：从定义出发，经过 FFT 降低复杂度，逻辑清晰。
  3. 消融实验的设计：分别拆解分解位置（输入端 vs 内嵌）和注意力类型（自注意力 vs 自相关），清晰展示了每个贡献。

* **最值得怀疑的部分**：
  1. 移动平均作为趋势提取是非常简化的假设，对于存在突变或阶梯变化的序列可能不够。
  2. "38% 平均提升"的统计方式可能放大了长步长上的极端值。
  3. FFT 在非平稳数据上的表现缺少理论保证。

* **适合哪些人阅读**：时序预测方向的研究生、信号处理与深度学习交叉领域的研究者、任何想理解"如何将领域知识融入深度架构"的人。

* **是否值得精读**：⭐⭐⭐⭐⭐ 强烈推荐。这是 LSTF 方向的里程碑工作，其分解思想被后续大量工作继承和发展。

* **推荐继续阅读**：
  1. FEDformer（频域增强的分解方法，Autoformer 的频域化延伸）
  2. DLinear（直接对分解后的趋势和季节分别用线性层，竟然超越了复杂 Transformer）
  3. PatchTST（通道独立 + Patch 思想，另一个意义上的突破）
  4. 原始 Informer（理解 Autoformer 改进了什么）
